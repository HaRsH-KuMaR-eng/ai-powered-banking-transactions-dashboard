# powerbi-retail-sales-dashboard
Interactive Power BI dashboard for retail sales analysis with ETL, Star Schema, DAX, KPI reporting, and business insights.





 Retail Sales Performance Dashboard
  Tech Stack: Power BI, Power Query, DAX, Excel, Data Modeling, Star Schema
  ○Developed an interactive Retail Sales Performance Dashboard in Power BI to analyze Sales, Net Sales, 
	    Profit, Orders, Quantity Sold, Discounts, and Promotional Performance using KPI-driven visualizations.
  ○ Performed ETL, data cleaning, transformation, and data modeling in Power Query by implementing
a Star Schema with optimized fact-dimension relationships.
  ○ Created DAX measures, calculated columns, and time-intelligence functions to build dynamic KPIs,
	sales trend analysis, and business performance metrics.
        ○ Designed interactive dashboards with slicers, drill-through, cross-filtering, and Top/Bottom 5 analysis
	to enable data-driven decision-making and business insights.
